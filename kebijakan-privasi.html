Kebijakan Privasi

Halaman ini menjelaskan secara ringkas bagaimana data digunakan saat Anda mengakses website Aksanira.

Data pada planner

Data yang Anda masukkan ke planner seserahan disimpan menggunakan penyimpanan lokal (localStorage) pada browser perangkat Anda. Data tersebut tidak otomatis dikirim ke server Aksanira.

Penggunaan data

Data planner digunakan untuk menampilkan daftar, ringkasan anggaran, dan status persiapan pada perangkat yang sama. Menghapus data browser atau menggunakan perangkat/browser berbeda dapat memengaruhi ketersediaan data tersebut.

Kontak

Untuk pertanyaan terkait privasi, silakan kunjungi halaman Hubungi Kami.

Catatan: Kebijakan ini merupakan draft awal dan perlu disesuaikan apabila Aksanira menambahkan analytics, formulir server-side, akun pengguna, pembayaran, atau layanan pihak ketiga.
