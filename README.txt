AKSANIRA — PATCH TOOL GRATIS: WEDDING SEATING PLANNER

File:
1. tools-gratis.html — menambahkan kartu Wedding Seating Planner.
2. wedding-seating-planner.html — halaman tool baru.

Fitur:
- Tambah meja dan kapasitas 1–30 kursi.
- Tambah nama tamu dan kelompok/keluarga.
- Tempatkan tamu ke meja melalui dropdown.
- Mencegah penempatan melebihi kapasitas.
- Ringkasan jumlah meja, kursi, dan tamu.
- Daftar isi meja dan indikator kapasitas.
- Cetak / Simpan PDF dan ekspor daftar tamu ke CSV.
- Simpan otomatis di localStorage browser.

Pemasangan:
Salin kedua file ke root repository (timpa tools-gratis.html), lalu commit dan deploy melalui Vercel.

Privasi dan batasan:
Data disimpan di browser perangkat ini, tidak dikirim ke server, dan tidak tersinkron otomatis antarperangkat. Gunakan data seperlunya dan jangan memasukkan informasi sensitif.
