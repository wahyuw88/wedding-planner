PATCH NAVIGASI TOOLS GRATIS + TOMBOL PLANNER AKSANIRA

File dalam patch:
- index.html: mengembalikan tautan "Tools Gratis" di navigasi utama.
- tools-gratis.html: halaman direktori tools gratis.
- kalkulator-budget-pernikahan.html
- wedding-countdown.html
- guest-list-estimator.html

Perubahan visual di index.html:
- Tombol "↺ Reset daftar" sekarang memakai warna mocha yang sama dengan "+ Tambah barang".
- Tombol "Cetak / Simpan PDF" sekarang memakai warna mocha yang sama dengan "+ Tambah barang".

Pemasangan:
1. Ekstrak ZIP.
2. Salin seluruh 5 file HTML ke direktori root website (folder yang sama dengan index.html), izinkan replace untuk index.html.
3. Commit dan deploy satu kali.

Catatan:
Patch ini memulihkan tautan dan halaman tools gratis pada website. Jika file tools gratis sudah ada, file tersebut diperbarui dengan versi tools yang sudah dibuat sebelumnya. Tidak ada artikel atau halaman lain yang diubah.
