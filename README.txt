AKSANIRA – Homepage Typography Patch

Perubahan: sistem ukuran font beranda dirapikan agar hierarki judul, deskripsi, label, input, tombol, tabel, panduan, navigasi, dan footer konsisten. Desktop menggunakan teks utama 15 px dan deskripsi planner 15 px. Mobile menggunakan teks utama 14 px, deskripsi planner 14 px, dan input 16 px agar nyaman disentuh serta menghindari auto-zoom pada sebagian browser iPhone.

Penerapan: ganti index.html di root repository dengan file ini, lalu commit dan deploy melalui Vercel. Patch hanya berisi index.html dan tidak mengubah halaman lain atau data planner. Belum diterapkan langsung ke website live.
