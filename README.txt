PATCH VISUAL SEO ARTIKEL AKSANIRA

Isi: 100 file HTML artikel yang diperbarui dan 10 ilustrasi SVG kategori di folder images/.

Cara pasang: ekstrak ke root repository GitHub. Pertahankan struktur folder: file HTML artikel tetap di root, folder images/ berada di root. Commit satu kali agar Vercel menjalankan satu deployment. Jangan hapus file website lain.

SEO visual: setiap artikel memiliki ilustrasi kategori, alt text spesifik berdasarkan judul, caption, dimensi gambar, lazy/eager loading sesuai posisi hero, Open Graph image, Twitter large image, dan properti image pada Article JSON-LD. URL artikel dan canonical tidak diubah.
