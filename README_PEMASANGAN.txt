PATCH TOOLS GRATIS AKSANIRA

Isi:
- tools-gratis.html: halaman direktori tools gratis.
- kalkulator-budget-pernikahan.html: simulasi biaya berdasarkan jumlah tamu dan kategori biaya.
- wedding-countdown.html: hitung hari menuju tanggal pernikahan.
- guest-list-estimator.html: estimasi tamu hadir dan porsi konsumsi.
- File HTML navigasi (jika ada): index.html, artikel.html, tentang.html, produk.html, kontak.html.

Cara memasang:
1. Ekstrak ZIP.
2. Unggah file HTML di dalam ZIP ke direktori root website yang sama dengan index.html.
3. Ganti file HTML navigasi dengan versi patch yang disertakan (jika tersedia).
4. Commit dan deploy satu kali.

Catatan:
- Patch hanya menambah 3 tools dan halaman direktori; tidak mengubah artikel atau file planner seserahan.
- Semua kalkulasi berjalan di browser, tanpa database/backend dan tanpa mengirim input pengguna ke server.
- Hasil adalah estimasi, bukan penawaran harga vendor.
- Uji di desktop dan HP setelah deploy.
